# 专注 B站

一款为**学习**而生的 B站 iPad 客户端。核心目标只有一个：看学科教学视频时，把干扰降到最低。

## 为什么做这个

B站有大量优质的学科与教学内容，但推荐流、弹幕、评论、热榜也在不断分散注意力。这款客户端刻意做减法，只保留「找到老师 → 打开课程 → 专心看」这条最短路径。

## 功能特点

- **登录只为高清** — 扫码登录仅用于获取高清画质，只显示自己的头像和昵称，不读取其他信息。
- **收藏老师，而非视频** — 本地只收藏 UP主（老师），让注意力停留在信任的教师和其教学内容上。
- **只搜账号，不搜视频** — 搜索仅能找到 UP主账号，搜不到零散的视频内容，避免顺手点开无关内容。
- **教师主页** — 展示老师的合集、系列与全部投稿，支持按发布时间 / 播放量排序。
- **纯净播放器** — 沉浸式全屏播放，只有倍速和清晰度（最高 1080P）两个控制项，无弹幕、无评论、无推荐。多分P / 多集课程用右侧抽屉切换。
- **登录过期提醒** — 会话失效时顶部横幅提示重新登录，临近过期提前预警。
- **亮 / 暗外观** — 侧边栏一键切换浅色、深色或跟随系统。

## 技术栈

- SwiftUI + Observation（`@Observable`），MVVM 架构
- 通过 [XcodeGen](https://github.com/yonaskolb/XcodeGen) 由 `project.yml` 生成工程
- iPad 专用，最低 iOS 17.0
- 调用 B站 Web 接口，含 WBI 签名与扫码登录

## 构建运行

```bash
# 生成 Xcode 工程
xcodegen generate

# 用 Xcode 打开
open BiliClient.xcodeproj
```

选择 iPad 模拟器或真机运行即可。

> 说明：本项目仅用于学习交流，未使用任何官方开放接口。
